PRODUCTS APP
Develop an application that manages a stock of products (TVs)
The application will read and write products to a CSV file like bellow:
Sample “products” file
code, brand, diagonal_size, width, height, display_technology, price, quantity
1, Samsung, 30, 145.1, 80, LED, 234.23, 4
2, Samsung, 28, 145.2, 80, LCD, 232.23, 1
Note. The file will display, on the first row, the comma separated field definitions of a product and on the following rows will display the values of each product (each product is defined in a row)

   - Code;
   - Brand;
   - Diagonal;
   - Display Technology;
   - Price;
   - Quantity;
   The list will contain the products that was read from the `products` file.
2. User can search products by code or brand. He will enter, in a text field above the list, a code or brand name and, in realtime, after every insertion of a character - the list will be changed, containing the products that may contain the searched text(list will be displayed as in TODO #1)
3. Add a new product. Add a button `Add Product` at the bottom of the list, that will prompt a dialog with all the necessarry data for a product ( the `Display Technology` should be a combo box ) and 2 button - `Submit` and `Cancel`.

4. Allow sorting. User will have 3 options:
1. by brand
2. by diagonal size
3. by price
	Sorting should be possible by clicking on the corresponding columns ( it will have 3 states: `Sorting from A to Z`, `Sorted from Z to A` and default state, which will display the products as they are in the file )
5. Sell a TV option: There should be a button a the bottom of the list, displayed as `Sell TV`. Upon pressing it, the user will be prompted with a dialog, which will contain a combo box with all the available product codes, and a button `Sell` ( the button can be made somewhat custom, like having a light-green color and a bold font ) and a `Cancel` button.
Also, that product's quantity must be updated in the "products" file.
